# PolishedWorld — Lessons register

> **Rev 1 · 2026-10-30** — first revision: lessons 1–184 in one place. Until now each session handoff carried only its own new lessons and pointed back to "1–N apply", so the full list existed nowhere. Each line is collected from the handoff that first wrote it; the decompositions cite lessons by number (49, 62, 64, 71, 73, 82, 93, 98, 103) and those citations resolve here. Origins marked *Adam to fill* are known only as "first listed" and are completed from the handoff documents.
> **Canonical:** `docs/PolishedWorld_Lessons.md` @ G0dlet/PolishedWorld — git wins.

Hard-won working rules for building PolishedWorld with Claude: how source is read, how claims are checked, how patches are verified and delivered. Every rule here cost at least one failed step to learn.

## How to read this register

- **Numbers are permanent.** A lesson is never renumbered or reused, because handoffs, decompositions and commit discussions cite them by number.
- **One line per lesson:** the rule in bold, then one sentence on why, then where it was first written.
- **Refinements get a new number.** When a later lesson sharpens an earlier one, the earlier line keeps its text and gains *refined by N*; read the highest number in the chain as current.
- **Origin** names the epic and task of the session that wrote the lesson, and the date of the handoff that carried it.
- **Adding lessons.** Handoffs keep carrying the lessons a session learns; they are appended here in batches, with the next free numbers, in the docs commit that closes an epic. Until then a handoff says which numbers it adds beyond this register.

## Lessons

1. **Mutate at least once per component, and prove an equivalent mutant equivalent.** A suite never seen killing a mutant is unproven. *(Origin: Adam to fill; first listed 2026-10-15)*
2. **"Nothing changed" needs an independent receipt that the code ran.** An unchanged state is also what a step that never executed leaves behind. *(Origin: Adam to fill; first listed 2026-10-15)*

4. **Assert the collection is non-empty before every "all satisfy X".** An empty collection passes every universal check. *(Origin: Adam to fill; first listed 2026-10-15)*
5. **Prose has no tests — your own new prose included; run its claims against the source before commit.** Nothing fails when a document is wrong. *(Origin: Adam to fill; first listed 2026-10-15)*
6. **A diagnostic that can succeed without having searched is worse than none.** It turns a gap into false confidence. *(Origin: Adam to fill; first listed 2026-10-15)*
7. **Read the diff before commit, and assert exactly one match before every replacement.** Zero or several matches mean the edit landed nowhere or somewhere else. *(Origin: Adam to fill; first listed 2026-10-15)*
8. **Changelogs are append-only and descending; read the top before numbering.** Anchoring on a remembered revision produced a duplicate Rev. *(Origin: Adam to fill; first listed 2026-10-15)*
9. **Confirm the branch with `git status`/`git rev-parse` before running the suite.** A green suite on the wrong branch is a receipt for nothing. *(Origin: Adam to fill; first listed 2026-10-15)*
10. **A mutation harness restores from copies and lets the assert stop the loop.** A harness that carries on after a failed assert leaves mutants on disk. *(Origin: Adam to fill; first listed 2026-10-15)*
11. **Expected values in a protocol are read and computed from the source.** Values written from memory make a correct run look wrong, or the reverse. *(Origin: Adam to fill; first listed 2026-10-15)*
12. **"Expected failures" are verified by name on every run, against the right configuration.** A count alone cannot tell the known failures from a new one. *(Origin: Adam to fill; first listed 2026-10-15)*
13. **Absence after a timer needs a time margin or a receipt.** Checked too early, "it didn't happen" and "it hasn't happened yet" look the same. *(Origin: Adam to fill; first listed 2026-10-15)*

17. **The prose loop sees new files only when it is run again after them.** A loop run before a file existed says nothing about that file. *(Origin: Adam to fill; first listed 2026-10-15)*
18. **A decision that arises during implementation is still a decision: flag it, log it, let Adam veto it.** Silent in-flight choices become undocumented design. *(Origin: Adam to fill; first listed 2026-10-15)*
19. **Receipts and anchors are quoted from the source, never from memory.** Hashes and line numbers drift between sessions. *(Origin: Adam to fill; first listed 2026-10-15)*

21. **A spy on a method misses aliases bound in the class body; when the question is "was anything written", compare state.** The alias still calls the original function. *(Origin: Adam to fill; first listed 2026-10-15)*
22. **The guide header and the commit message are prose too.** They are read as claims and go stale like any other text. *(Origin: Adam to fill; first listed 2026-10-15)*
