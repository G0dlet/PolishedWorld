# PolishedWorld — Dev board

What is being built, one card per larger piece of work. This file is the page
at `/board/` on the game's website, read on every visit: move a bullet between
the three columns below and the page shows it at once. Cards move when an epic
starts and when it closes; `docs/roadmap.md` stays the truth, and this board
is its shop window for players.

Rules the page follows: only the three headings below are columns, a card is
a top-level bullet under one of them, and anything else is ignored.
